Why I'm a fit

The role asks for someone who validates GPU hardware before it reaches production, writes Python and shell to automate it, and documents every command and outcome. That is exactly what I built, and it's all public and running against real hardware.

I didn't do a course project. I built a validation pipeline and used it to gate a node into production, and I can walk you through every design decision in it.

The work, mapped to the role

  • GPU validation — NVML health checks (temperature, power, PCIe link state, ECC, clocks) plus a CUDA burn test that stresses the card under load, because an idle card hides defects.
  • Python + shell — six small Python programs and a bash verify script, each with a single job and a clear exit code.
  • Ansible — a playbook that orchestrates the whole flow: validate, burn, network check, combine, submit.
  • Data-center networking — DHCP, IPv6, and ICMP readiness checks before a node is allowed to onboard.
  • Documentation — every command, observation, and outcome is captured in a runbook and an audit trail, not just in my head.
