# Infrastructure Production Labs

Arthur Perchatkin. Live page: https://arthurperch.github.io/infrastructure-labs/

These are labs I built to learn production infrastructure. Each one is a real repo you can clone and run.

| Lab | What it is | Repo |
|---|---|---|
| GPU Validation Pipeline | Checks a GPU, then a gate decides PROVISION / HOLD / RMA | [node](https://github.com/arthurperch/gpu-validation) + [gate](https://github.com/arthurperch/gpu-onboarding-gate) |
| AWS Security Auditor | Walks IAM, EC2, S3, and security groups and writes a report | [aws-security-auditor](https://github.com/arthurperch/aws-security-auditor) |
| Gridwatch | Looks at live connections, flags blocked IPs and odd processes | [gridwatch](https://github.com/arthurperch/gridwatch) |
| flask-mcp-server | Lets an AI assistant talk to a Flask app and a few AWS calls | [flask-mcp-server](https://github.com/arthurperch/flask-mcp-server) |

Lab environments only. No production secrets.

GitHub: [arthurperch](https://github.com/arthurperch)
